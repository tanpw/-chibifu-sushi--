### 三、插画 PNG（约 42 张 · 编号 + 首字命名）

- 命名规则：**`序号 + 该句首字.png`**，与《预习：《赤壁赋》.md》"逐句文字生图提示词"的 42 句一一对应。
- 例：`1任.png`（壬戌之秋泛舟）、`26寄.png`（寄蜉蝣于天地）、`36惟.png`（江上清风山间明月）、`42相.png`（枕藉舟中东方既白）。
- 画风：绘本儿童插画，16:9 宽幅，水彩质感、蓝金色调、古风 Q 版人物（含统一苏轼形象）。

### 四、朗读 MP3（分句音频 · 编号 + 首字命名）

- 命名规则与插画一致：`序号 + 首字.mp3`，与 42 句原文一一对应。
- `0.mp3` 为全文/片头音频；`6纵1.mp3` 为第 6 句备用版本。
- 用法：看插画 → 听分句 → 跟读，配合"朗读版全文（注音+停顿）"使用，适合背诵。

## 📖 使用建议（学习路径）

1. **读方法**：先看 [预习：语文预习步骤.md](预习：语文预习步骤.md)，了解六步预习法。
2. **做预习**：对照 [预习笔记：《赤壁赋》.md](预习笔记：《赤壁赋》.md) 读课文、圈字词、填模板（约 20～25 分钟）。
3. **查翻译**：逐句不懂处查《预习：《赤壁赋》.md》"课文原文与逐句翻译"。
4. **听读背诵**：打开分句 MP3 + 插画，听一句、看一图、跟读一句。
5. **课堂听讲**：带着笔记里的"我的疑问"重点听讲。
